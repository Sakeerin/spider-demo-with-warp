How to try locally (PowerShell)
•  List leads
◦  powershell -NoLogo -NoProfile -Command "Invoke-RestMethod -Uri 'http://localhost:3001/api/leads' | ConvertTo-Json -Depth 4"
•  Create a lead
◦  powershell -NoLogo -NoProfile -Command "$b=@{ customerId='{{customerId}}'; serviceType='painting'; description='House painting'; location='Bangkok'; budgetMin=50000; budgetMax=80000; urgency='low'; status='new' } | ConvertTo-Json | Invoke-RestMethod -Method Post -Uri 'http://localhost:3001/api/leads' -ContentType 'application/json' -Body $input"
◦  Replace {{customerId}} with an existing user ID (from the seed or DB).
•  List contractors
◦  powershell -NoLogo -NoProfile -Command "Invoke-RestMethod -Uri 'http://localhost:3001/api/contractors' | ConvertTo-Json -Depth 4"
•  Create a contractor
◦  powershell -NoLogo -NoProfile -Command "$b=@{ userId='{{userId}}'; businessName='Beta Co.'; experience=3; successRate=0.75; responseTime=4 } | ConvertTo-Json | Invoke-RestMethod -Method Post -Uri 'http://localhost:3001/api/contractors' -ContentType 'application/json' -Body $input"
◦  Replace {{userId}} with an existing user ID.
